# CampusFind

CampusFind is a frontend-only lost-and-found report browser with fictional sample data.

## Run locally

From this directory, install dependencies if needed and start the Vite development server:

```sh
npm install
npm run dev
```

Open the local URL printed by Vite. To verify a production build, run `npm run build`.

## Browse reports

Search matches keywords in the title, description, university, campus, and approximate location. Use the university/campus selector and the All, Lost, or Found controls together to narrow the feed. Open a report by selecting its title; Back to reports preserves the current search and filters.
